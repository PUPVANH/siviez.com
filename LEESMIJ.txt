siviez.com — korte notitie (NL)
================================================================

De volledige, up-to-date documentatie staat nu in README.md
(in het Engels — internationale standaard voor code-projecten).

Snelstart:
  npm install      -> pakketten installeren (eerste keer)
  npm run dev      -> lokaal draaien op http://localhost:4321
  npm run build    -> productie-build

Deployen:
  Elke push naar 'main' zet automatisch live op Vercel (~30-60s).

Foto's toevoegen:
  1. Plaats de foto in public/photos/<thema>/  (hike/ski/apartment/village)
  2. Geef een beschrijvende naam: thema-onderwerp-detail.jpg
  3. Verwijs ernaar met een duidelijke alt-tekst

Zie README.md voor alle details over de structuur.

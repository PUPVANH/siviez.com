# siviez.com

Travel guide to Siviez, Valais, Switzerland — and home to **Rosablanche C34**, a ski-in/ski-out apartment for 7.

Live at [siviez.com](https://siviez.com).

Part of [PUPVANH Projects](https://pupvanh.vercel.app).

## Stack

- [Astro](https://astro.build/) static site
- [Vercel](https://vercel.com/) hosting + Analytics
- Content in NL / EN / FR

## Development

```bash
npm install
npm run dev
```

Site opens at [http://localhost:4321](http://localhost:4321).

## Deployment

Every push to `main` auto-deploys to Vercel.

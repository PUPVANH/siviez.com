2. ACCURATE ALT-TEKSTEN
   Elke foto heeft nu een correcte, beschrijvende alt-tekst met
   de echte plaatsnamen (Cleuson, Saint-Barthélémy, Printse,
   Refuge Saint-Laurent, Grand Désert, Combatseline, Sion).
   Goed voor SEO én blinden.

3. COMBATSELINA -> COMBATSELINE (15 correcties)
   Je site schreef "Combatselina" (met -a-). De officiële
   spelling is "Combatseline" (met -e-) - bevestigd door
   nendaz.ch, AllTrails, skiresort.com. Overal gecorrigeerd.

   - Auberge de Siviez / Les Gentianes (100 bedden)
   - ESS Nendaz skischool (bureau in Rosablanche + uren)
   - De 3 liften vanuit Siviez (Combatseline/Tortin/Plan du Fou)

   Pak deze zip uit, kopieer alle bestanden in siviez.com.
   .git blijft staan, mijn bestanden komen ernaast.

STAP 4 - GitHub Desktop -> Commit -> Push
   Je ziet veel wijzigingen (foto's hernoemd + code). Normaal.
   Summary: "Accurate photo names, alt text, Combatseline fix, local data"
   Commit to main -> Push origin. Wacht ~1 min.

CONTROLEREN NA DEPLOY
================================================================

Klik alle 4 pagina's af - alle foto's moeten laden:
   siviez.com            (hero + kaarten)
   siviez.com/hike       (hero + galerij)
   siviez.com/ski        (hero + complex)
   siviez.com/appartement (hero + galerij, geen kapotte foto meer)

Als een foto niet laadt: rechtermuisklik -> openen in nieuw
tabblad -> stuur mij het pad dat 404 geeft.
